# Ghousiya M — Developer Portfolio

A responsive dark 3D-inspired developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in a modern browser.
3. For local hosting, run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Deploy
Upload the complete extracted folder to a static hosting provider (for example GitHub Pages, Netlify, or Vercel). Keep the `assets` folder and its structure unchanged.

## Certificates
The five uploaded certificate images are included in `assets/certificates/`.
The NPTEL certificate is shown in the dedicated NPTEL section. Other uploaded certificates are grouped separately.
To add more certificates, copy the image into `assets/certificates/` and duplicate a `.cert` card in `index.html`, updating its image path, title, institution and year from the actual certificate.
